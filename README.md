# Bbumi Blog

A minimal personal blog built with [Astro](https://astro.build), TypeScript, and Content Collections. Deploys to GitHub Pages via Actions.

## Local development

Requires Node 20+ (matching the `withastro/action` runtime).

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # produces ./dist
npm run preview    # serves the built output
```

## Adding a new article

1. Create a Markdown file in `src/content/articles/`. The filename (kebab-case) becomes the URL slug — e.g. `notes-on-shipping.md` → `/articles/notes-on-shipping/`.
2. Use this frontmatter:

   ```yaml
   ---
   title: Notes on Shipping
   subtitle: Optional one-line subtitle
   category: Engineering
   pubDate: 2026-05-19
   description: Optional, used for SEO + social previews.
   heroImage: /images/articles/notes-on-shipping.jpg
   ---
   ```

   `subtitle`, `description`, and `heroImage` are optional. `heroImage` is a path served from `public/` (drop the file under `public/images/articles/`).

3. Write the body in Markdown. Code fences are highlighted with Shiki using a `github-light` / `github-dark-dimmed` pair that follows the page theme.

The home page lists the latest 5 entries; the full list lives at `/articles/`.

## How deploy works

`.github/workflows/deploy.yml` builds the site with [`withastro/action`](https://github.com/withastro/action) on every push to `main` and publishes to GitHub Pages.

To enable Pages on a new repo:

1. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
2. Edit `astro.config.mjs` and set `site` to your public URL.
   - User/org site (e.g. `https://yourname.github.io`): leave `base` commented out.
   - Project site (e.g. `https://yourname.github.io/bbumi-blog/`): uncomment `base` and set it to `'/bbumi-blog/'`.
3. Push to `main`. The workflow will build and deploy.

## Before your first deploy — edit these

- `astro.config.mjs` → `site` (and `base` if it's a project site).
- `src/consts.ts` → `title`, `tagline`, `description`, `author`, `twitter`.
- `src/pages/about.astro` → replace the placeholder About copy with your own.

## Tech notes

- Content Collections + Zod schema in `src/content/config.ts` keep frontmatter type-safe.
- `@astrojs/sitemap` emits `sitemap-index.xml`.
- `/rss.xml` is generated by `src/pages/rss.xml.js` via `@astrojs/rss`.
- Theme toggle: light/dark stored in `localStorage` under the key `theme`; the initial value is set by an inline script in `<head>` to avoid a flash. First-visit default follows `prefers-color-scheme`.
- Styling is vanilla CSS using custom properties — see `src/styles/global.css`.
